# Product Inventory & Analytics Dashboard

JavaScript capstone mini project.

## Structure
- `index.html` - page with a Run button and output area
- `css/style.css` - styling
- `js/script.js` - all program logic

## How to run
Open `index.html` in a browser, tap **Run Project**, and enter a product name and price when prompted.
Console output also appears in the browser console (F12 on desktop).

## Concepts covered
1. Input with `prompt()` and `Number()` conversion, objects in an array
2. `if...else` and `switch` for validation and category badges
3. Loops with `break` / `continue`
4. Regular and arrow functions, default parameters, local scope
5. `forEach()`, `filter()`, `map()`
