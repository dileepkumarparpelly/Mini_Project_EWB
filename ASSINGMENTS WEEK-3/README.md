# JavaScript Assignments 1-6

## Structure
- `assignment1.js` ... `assignment6.js` - one solution file per assignment
- `index.html` - pick an assignment and run it, with output shown on the page
- `css/style.css` - styling

## How to run
Open `index.html` in a browser, choose an assignment, tap **Run**.
Or run in Node.js (except Assignment 2, which needs a browser for `prompt()`):

    node assignment1.js

## Topics
1. Variables, data types, console operations
2. Operators, expressions, input handling
3. Conditional logic (if...else, switch, ternary)
4. Loops (for, while + break, do...while + continue)
5. Functions and scope (standard, arrow, default parameters)
6. Arrays, objects, forEach / filter / map
